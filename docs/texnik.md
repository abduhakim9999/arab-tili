# Техник маълумот (сайт, эшитиш, овозлар, бот)

Бу файл — техник масалалар бўйича ягона манба. Грамматика қоидалари — `docs/kitob-konspekti.md`. Иш тартиби — `CLAUDE.md` ва `yangi-dars` скилли.

## 1. Сайт
- https://abduhakim9999.github.io/arab-tili/ — GitHub Pages, `main` дан. Telegram Mini App: `t.me/Arabtilihivar_bot/darslar`.
- Дастур номи ва китоб номи: «نُورُ الطَّالِبِ» (Нурут толиб). Қаҳрамон устоз — китоб муаллифи. Саҳифада манба ёрлиқлари кўрсатилмайди.
- Дарслар: 1-китоб 1–5; 2-китоб 70–74, 91–94. Дастурдаги дарс рақами аудиодагидан фарқ қилиши мумкин (масалан 94 = «العربية بين يديك» 2-китоб 79-дарс); китоб ва боб рақами китобдагидек.
- Ҳар дарс: бисмиллаҳ → дарс рақами (янги ваҳданинг 1-дарсида ваҳда номи ҳам; `build.py` даги SHOWU). Ўз аудиосида бўлса ўшаники, бўлмаса сунъий овоз (Mehdi).
- Бош саҳифа: Ruqaa «نُورُ الطَّالِبِ» (ўзгармайди) → панел Сарф · Феъллар · Эшитиш → «Давом этиш» → 1-китоб, 2-китоб. Минимализм: прогресс матни, ортиқча ёзув йўқ; версия фақат «i» ойнасида.
- Дизайн: минимал (iPhone услуби), кундузи оч, тунда тўқ зумрад; дарс ичида тилла ранг йўқ. Шрифт: Noto Naskh (саҳифага жойланган). Ҳамма матн кирилча.

## 2. Йиғиш
- Иш файллари `src/build/` да — аввал `src/build/README.md` (тиклаш; йўллар скриптларда қаттиқ ёзилган).
- Дарс маълумоти: `src/build/scratchpad/dNN/` (`dataNN.py`, `vocNN.py`, `jmNN.py`, `quizNN.py`, `genNN.py`, `dlgNN.mp3`). Янги дарс энг яқин дарсдан нусха олиб ёзилади (1-китоб суҳбати → d05; 2-китоб матни → d94).
- `site/build.py`: LESSONS, UNIT, HDR/LN, TITLE, DROP0, LISTEN; иконка — `index.tpl.html` даги ICO.
- `build.py` натижасидаги эски дарслар реподагидан фарқ қилади (тўғридан-тўғри тузатилган). Янги дарсда фақат янги файллар ва `index.html` нусхаланади; `sw.js` га қўлда қўшилади; `tinglash.html` га янги объект қўлда қўшилади (93 нинг Таркиб `t` майдони йўқолмасин).
- Кичик ўзгаришда тайёр файл тузатилади ва `src/build` даги нусхаси ҳам.
- Версия: `sh src/build/bump.sh` (қўлда sed йўқ). `sw.js` 3-қаторидаги версия ошганини текшир.
- Фойдаланувчи кўриб чиқиши керак бўлган катта ўзгариш — алоҳида branch, «ҳа» дан кейин main.
- Битта репода бир вақтда икки чатда ишланмайди; ишдан олдин `git pull`. Репо катта: `git clone --depth 1 --filter=blob:none --sparse` + `git sparse-checkout add …`; коммитда `git add --sparse -A`.

- Таркиб қутиси: гап устида бир сўз (исмийя / феълийя / таажжуб); яширин сўз пунктир рамкада ўз ўрнида; шибҳи жумла картаси [мутааллиқ] → [сўзлар], ортиқча ёзувсиз; ST_FIX / SJ_FIX — `site/tarkib.py` (калит такрорланмасин).

- «Эшитди» фақат сўровномада овоз бериш орқали (бир вариантли poll, 23:59 гача, 21:00 эслатма); эшитмаганлар → Қора рўйхат. Натижада фақат эшитди/эшитмади.
